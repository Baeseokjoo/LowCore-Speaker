# LOWCORE 요구사항 정의서 (PRD)

- 프로젝트명: LOWCORE (로우코어) — 음악·영상 작업용 모니터 스피커 단일 상품 사이트
- 작성일: 2026-11-17
- 배포 주소: https://baeseokjoo.github.io/LowCore-Speaker/
- 근거 문서: docs/PROJECT_CONTEXT.md

---

## 1. 프로젝트 개요

### 목적
방문자가 PC 스피커와 LOWCORE의 저음 차이를 직접 들어 보고, 소리가 기기마다 달라지는 이유를 이해하도록 돕는다.

### 방문자가 원하는 것
- 주요 방문자: 유튜버·영상 편집자, 홈레코딩 입문 작곡가
- 소리가 기기마다 달라지는 이유를 이해하고 싶다.
- 사기 전에 PC 스피커와의 차이를 직접 확인하고 싶다.

### 핵심 행동
- 가장 중요한 행동: 비교 체험 재생 — 같은 트랙을 PC 스피커와 방문자가 고른 LOWCORE 모델(LC-5-105 / LC-8-112)로 번갈아 듣기
- 보조 행동: 제품 상세 보기 → 구매 버튼 누르기 (결제 화면은 만들지 않음)

| R-08 | 방문자는 고른 기기의 소리를 재생하고 멈출 수 있다. | B10, S02 | 공통 | 상 | 이미지를 고르기 전에는 B10이 보이지 않고, 고르면 선택한 이미지 안 하단에 0.3초 동안 나타난다. B10을 누르면 0.3초 페이드인으로 재생, 다시 누르면 0.2초 페이드아웃으로 정지한다. 페이지 진입·스크롤·이미지 선택만으로는 소리가 나지 않는다. |

| R-10 | 방문자는 기기를 바꿔도 같은 구간을 이어서 비교할 수 있다. | B07, B08, B09, B10, C03 | 공통 | 중 | 재생 중 다른 이미지를 누르면 소리가 멈춘다. 이어서 B10을 누르면 멈췄던 위치부터 재생된다(처음으로 돌아가지 않는다). |
| R-11 | 방문자는 플레이바로 재생 위치를 확인하고 원하는 위치로 옮길 수 있다. | C03 | 공통 | 중 | 재생 중 플레이바 진행선이 실제 재생 위치와 함께 움직인다. 재생 중·정지 중 모두 누르거나 끌면 그 위치로 이동한다. 키보드 ←→ 로 5%씩, Home·End로 처음·끝으로 이동한다. 누르는 영역 높이는 44px이다. |
| R-12 | 방문자는 휴대폰에서도 기기 선택과 재생 조작을 한 화면에서 할 수 있다. | S02, B07, B08, B09, B10, C03 | 모바일·태블릿 | 상 | 375px에서 이미지 3개가 한 줄(간격 10px)로 보이고, 모델 라벨은 이미지 바깥 위 가운데(14px)에 있다. 767px 이하에서는 B10·선택한 모델 이름·C03이 이미지 묶음 아래에 표시되며, 이미지를 골라도 아래 내용의 세로 위치가 바뀌지 않는다. 768~1023px에서는 선택한 이미지 안 하단에 표시된다. |

| R-14 | 방문자는 기기별 저음 한계를 막대로 비교할 수 있다. | S03 | 공통 | 하 | "낮을수록 깊은 저음" 아래 막대 3개가 20~200Hz 로그 눈금(20·50·100·200)에 PC 스피커 150Hz / LC-5-105 50Hz / LC-8-112 35Hz 값과 함께 표시된다. 막대 값은 R-09 필터 주파수와 같다. |
| R-15 | 방문자는 태블릿·휴대폰에서 이유 설명을 위에서 아래로 차례대로 읽을 수 있다. | S03 | 모바일·태블릿 | 하 | 1023px 이하에서 제목 → 저음 한계 막대 → 본문 → 키워드 순서로 한 열에 쌓인다. 375px에서 가로 스크롤이 없다. |
| R-16 | 방문자는 두 모델의 요약을 나란히 보고 비교할 수 있다. | B03, B04 | 공통 | 중 | S04 제목 "LOWCORE 모델 비교하기" 아래 LC-5-105·LC-8-112 카드가 나란히 놓이고, 각 카드에 모델 이미지, 모델명(24px), 제품 요약 세 줄(18px, 오키드 글자)이 표시된다. 1024~1067px에서는 요약 글자가 16px로 바뀌어 세 줄을 유지한다. |
| R-17 | 방문자는 모델 카드를 눌러 상세 사양을 보고, 다른 모델로 바꾸거나 다시 접을 수 있다. | B03, B04, S04 | 공통 | 중 | 카드를 누르면 0.9초 동안 상세 칸이 펼쳐지고 사양 12항목이 두 열(6개씩)로 표시되며 값이 사양표와 일치한다. 다른 카드는 화면 끝으로 밀려나 흐림 5px + 밝기 0.7이 된다. 흐린 카드를 누르면 그 모델로 바뀌고, 펼친 이미지 프레임을 누르면 접힌다. 펼쳐도 주소(URL)는 바뀌지 않는다. |
| R-18 | 방문자는 구매 버튼을 눌러 구매 가능 여부를 안내받을 수 있다. | B05 | 공통 | 중 | 상세 칸 하단에 구매(왼쪽)·체험하기(오른쪽)가 두 모델 모두 같은 순서로 놓인다. 구매를 누르면 같은 화면에 제목 "준비 중입니다", 본문 "실습용 사이트로 구매가 불가합니다."와 닫기 버튼이 있는 안내창이 뜬다. 닫기 버튼·Esc·바깥 클릭으로 닫히고, 닫힌 뒤 키보드 포커스가 구매 버튼에 있다. 결제 화면으로 이동하지 않는다. |
| R-19 | 방문자는 태블릿·휴대폰에서 모델 카드를 눌러 바로 아래에서 상세 사양을 볼 수 있다. | B03, B04, S04 | 모바일·태블릿 | 중 | 1023px 이하에서 카드 2장이 세로로 놓인다. 카드를 탭하면 그 카드 바로 아래로 상세 정보가 0.9초 동안 펼쳐지고 테두리가 오키드로 바뀐다. 다시 탭하면 접히고, 다른 카드를 탭하면 그 카드 아래로 바뀐다. 다른 카드는 흐려지지 않는다. 375px에서 가로 스크롤이 없다. |

## 4. 검토 메모
