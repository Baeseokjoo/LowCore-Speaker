## 4. 화면 구성

### P01 메인 (위쪽 행)
섹션은 위에서 아래로 다음 순서로 쌓입니다.

**헤더**
- 왼쪽: 브랜드명 (회색 선)
- 오른쪽: M01 상단 메뉴. 항목이 정해지지 않아 회색 점선 상자에 "메뉴 항목 추후 결정"으로 표시

**S01 히어로**
- 브랜드명 (회색 선)
- 메인카피 (굵은 회색 선 2줄)
- 서브카피 (회색 선 2줄)
- B01 체험 시작 버튼

**S02 비교 체험**
- 섹션 제목 (굵은 회색 선)
- 안내 상자: 헤드폰 착용 권장 (회색 선 2줄)
- 안내 문구: 모델을 선택한 뒤 재생 버튼을 누르면 음원이 재생됩니다.
- 이미지 세 개가 가로로 나란히 배치 (자동 재생 없음)
  - B07 PC 스피커 이미지 (X 상자): 누르면 선택 (재생 중이면 소리 멈춤)
  - B08 5인치 모델 이미지 (X 상자): 선택된 상태를 예로 그림. 진한 테두리로 선택 표시. PC 스피커, 8인치 모델 이미지를 눌렀을 때도 같은 방식
    - 이미지 안 하단: 재생 컨트롤 영역
      - B10 재생 / 정지: 둥근 재생 버튼. 누르면 소리 재생 (선택만으로는 재생되지 않음)
      - C03 플레이바: 재생 위치 표시
    - 재생 중 다른 모델을 선택하면 소리 멈춤
  - B09 8인치 모델 이미지 (X 상자): 누르면 선택 (재생 중이면 소리 멈춤)

**S03 이유 설명**
- 섹션 제목 (굵은 회색 선)
- 본문 (회색 선 6줄)

**S04 모델 선택**
- 섹션 제목 (굵은 회색 선)
- 모델 카드 두 장이 나란히 배치
  - B03 5인치 모델 카드: 맨 위 모델 이미지 (X 상자) + 모델명 + 제품 요약 (회색 선 3줄)
  - B04 8인치 모델 카드: 맨 위 모델 이미지 (X 상자) + 모델명 + 제품 요약 (회색 선 3줄)
- 안내 문구: 두 카드가 나란히 보임 · 누른 카드 옆으로 상세 정보가 가로로 펼쳐짐 (아래 행 상태 화면 참고)

### P01 메인 · S04 상세 펼침 상태 · 5인치 선택 (아래쪽 행)
B03 5인치 카드를 누른 상태입니다.

- B03 5인치 카드 (선택됨): 카드가 가로로 넓어지며 두 칸으로 나뉨
  - 왼쪽 칸 (카드): 카드가 자연스럽게 확대되며 이미지 아래 텍스트(모델명, 제품 요약)가 사라지고, 모델 이미지 (X 상자)가 칸 높이만큼 커짐
  - 오른쪽 칸 (상세 정보, 연한 회색 배경): 다른 카드가 밀려난 방향(오른쪽)으로 가로로 펼쳐짐
    - 위: 상세 정보 내용 (회색 선 8줄)
    - 가장 하단: 하단 버튼 영역. B05 구매와 B06 체험하기를 같은 위치에 나란히 배치
- B04 8인치 카드 (모델 이미지 포함): 펼쳐진 상세 정보에 밀려 더 오른쪽으로 이동해 화면 끝에 일부만 보이고 블러 처리됨. 누르면 선택이 8인치로 바뀜

### P01 메인 · S04 상세 펼침 상태 · 8인치 선택 (아래쪽 행)
B04 8인치 카드를 누른 상태입니다. 5인치 선택 상태를 좌우로 뒤집은 배치입니다.

- B04 8인치 카드 (선택됨): 카드가 가로로 넓어지며 두 칸으로 나뉨
  - 오른쪽 칸 (카드): 카드가 자연스럽게 확대되며 이미지 아래 텍스트(모델명, 제품 요약)가 사라지고, 모델 이미지 (X 상자)가 칸 높이만큼 커짐
  - 왼쪽 칸 (상세 정보, 연한 회색 배경): 다른 카드가 밀려난 방향(왼쪽)으로 가로로 펼쳐짐
    - 위: 상세 정보 내용 (회색 선 8줄)
    - 가장 하단: 하단 버튼 영역. B05 구매와 B06 체험하기를 같은 위치에 나란히 배치 (5인치 선택 상태와 같은 순서)
- B03 5인치 카드 (모델 이미지 포함): 펼쳐진 상세 정보에 밀려 더 왼쪽으로 이동해 화면 끝에 일부만 보이고 블러 처리됨. 누르면 선택이 5인치로 바뀜
