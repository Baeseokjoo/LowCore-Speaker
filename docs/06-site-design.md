- 여백은 넓게, 한 묶음 안은 촘촘하게: 묶음 안 24px 이하, 묶음 사이 64px 이상

- 메인 페이지 전체 높이: 섹션 4개 × 화면 높이 + 푸터 (데스크톱 한 화면 맞춤, 4-2)

### 4-2. 데스크톱 한 화면 맞춤 (2026-11-16)

가로 1024px 이상, 브라우저 세로 700px 이상에서 S01~S04를 각각 화면 높이(100vh)에 맞춥니다. 글자 크기는 그대로이고, 여백과 이미지 크기만 화면 높이에 맞춰 줄이며 위 표의 크기보다 커지지 않습니다. 스크롤 스냅은 쓰지 않습니다.

| 섹션 | 바뀌는 값 |
|---|---|
| 공통(S02~S04) | 위 여백 `header-height` + 24px, 아래 여백 40px, 내용은 세로 가운데 |
| S01 히어로 | 높이 = 화면 높이 |
| S02 비교 체험 | 이미지 위 간격 40px. 이미지 3개 묶음 폭 = min(100%, (화면 높이 − 460px) × 0.8 × 3 + 64px) |
| S03 이유 설명 | 내용 세로 가운데만 |
| S04 모델 선택 | 카드 위 간격 48px. 카드 이미지 = min(440px, 화면 높이 − 450px). 가로 1024~1067px에서는 카드 요약 글자 16px(요약 세 줄 유지, 글자 크기 예외) |
| S04 펼침 | 높이 = 화면 높이 − 281px (456~600px). 세로 900px 미만에서는 상세 칸 위아래 여백 28px, 사양 항목 위아래 4px. 세로 700~736px에서는 섹션이 최대 37px 길어짐 |

## 6. 분위기와 말투

- 한 줄 설명: 작업실 선배가 옆에서 말해 주듯, 짧고 차분한 존댓말로 — 꾸미지 않고 직접 듣고 판단하게 한다.
- 예시 문장: "같은 트랙을 세 기기로 번갈아 들어 보세요. 차이는 직접 듣고 판단하시면 됩니다."
- 이렇게: 한 문장에 한 가지 · '-해 보세요' 권유형 · 사실만 · 감탄사와 느낌표 없음
- 피하기: '압도적인', '역대급' 같은 과장 · 할인·한정 강조 · 근거 없는 비교 수치 · 이모지
- 문장 속 브랜드명은 대문자 `LOWCORE`, 한글 표기는 '로우코어'. 로고 이미지는 필기체 'LowCore' 그대로 씀

- S02 정면 컷은 블러 상태에서도 기기를 알아볼 수 있도록 윤곽이 뚜렷하게
- 크기: 실제 비율이 아니라 크기 순서를 단계로 표현함. 이미지 칸 높이 기준으로 PC 스피커 60% / 5인치 70% / 8인치 80%. 폭은 기기 모양에 따름
- S04 기본 카드도 같은 기준(5인치 70% / 8인치 80%). 펼친 이미지 프레임에서는 기기가 하나만 보이므로 두 모델 모두 80%로 같게 키움
- 정렬: 칸의 가로·세로 가운데
- 5인치·8인치 컷(정면·비스듬히 4장)에는 우퍼 아래 앞면 하단 가운데에 확정 로고 흰색 버전을 넣음. 폭은 앞면 폭의 약 40%. PC 스피커에는 넣지 않음
- 캔버스: S02 정면 1600×2000(4:5), S04 비스듬히 2000×2000(1:1). 배경을 딴 뒤 기기 윤곽에 맞춰 여백을 잘라 내고(trim), 크기 단계는 코드에서 맞춤
