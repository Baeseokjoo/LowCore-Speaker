# NavMenu

섹션 바로가기 메뉴입니다. 헤더와 푸터에서 같은 항목을 씁니다.

- 넣을 것: `items`(`label`, `href`, `current`), `onNavigate`. 이동은 부드러운 스크롤로 처리합니다.
- 호버하면 `hover-tint` 회색 알약이 생기고, 지금 보고 있는 섹션(스크롤로 도착했거나 클릭했을 때)은 `orchid-tint` 바탕 + `orchid` 글자가 됩니다. 클릭한 순간 바로 바뀌고, 스크롤하는 동안 다른 항목으로 깜박이지 않게 합니다.
- 항목은 Experience(S02) / Why(S03) / Model(S04)입니다(2026-11-13 확정).
- 휴대폰(767px 이하)에서도 헤더 한 줄에 그대로 둡니다. 글자 13px, 알약 여백 6×10px(2026-11-16).
