# ModelCard

S04 모델 선택의 기본 상태 카드(B03 5인치 / B04 8인치)입니다. 카드 전체가 버튼입니다.

- 넣을 것: `kind`, `name`(LC-5-105 / LC-8-112), `children`(제품 요약 세 줄), `onOpen`.
- 구성은 위에 모델 이미지(440px), 아래에 글자 영역입니다. 글자 영역은 왼쪽 끝 모델명(`h4`) · 오른쪽 끝 제품 요약(`body-lg` 18px, `orchid` 글자)을 가로로 놓고, 사이 간격은 남는 공간만큼 자동(최소 `space-4`), 모델명은 요약 세 줄의 세로 가운데에 둡니다(2026-11-13). 두 장을 같은 폭으로 나란히 놓습니다.
- 데스크톱에서는 호버하면 커서 방향으로 최대 약 9° 기울고 뒤로 연기 빛이 비칩니다(소비하는 쪽 `style`). 누르면 `DetailPanel`로 바뀝니다.
- 가격·후기는 확정 전까지 넣지 않습니다. 사양은 카드가 아니라 `DetailPanel`에만 둡니다.
