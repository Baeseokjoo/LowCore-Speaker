# Button

알약 모양 버튼입니다. `primary`는 `orchid` 채움 + `on-orchid` 글자, `ghost`는 투명 바탕 + `outline` 테두리입니다.

- 넣을 것: `children`(버튼 글자, 2~4자 동사형: 체험 시작, 구매, 체험하기, 닫기), 이동이면 `href`, 아니면 `onClick`.
- `primary`는 한 화면 높이 안에 하나만 둡니다(S01 체험 시작, S04 구매). 나머지 행동은 `ghost`입니다.
- `breathe`와 `icon="arrow-down"`, `size="lg"`는 S01 B01 체험 시작에만 씁니다. 4초 주기로 빛이 숨 쉬고, 호버하면 2px 떠오르며 화살표가 내려갑니다.
- 크기: `lg` 56px(히어로), `md` 52px(기본), `sm` 44px(안내창). 44px보다 작게 만들지 않습니다.
- 하지 말 것: 할인·한정 문구, 느낌표, 오키드 버튼 두 개 나란히.
