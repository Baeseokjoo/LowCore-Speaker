# PlayControl

재생/정지 버튼(B10)과 플레이바(C03)입니다. 선택된 비교 이미지 안 하단에만 나타납니다.

- 넣을 것: `playing`, `progress`(0~100), `onToggle`. 휴대폰용으로 `inline`(이미지 밖 일반 흐름에 놓음), `label`(선택한 모델 이름, 버튼 이름에도 붙음)이 있습니다.
- 휴대폰(767px 이하)에서는 비교 이미지가 작아 이미지 묶음 아래에 `inline`으로 넓게 놓습니다(2026-11-16).
- 받침 배경이나 테두리 없이 이미지 위에 바로 놓습니다. 트랙은 `track`, 진행선과 버튼은 `orchid`입니다.
- 자동 재생하지 않습니다. 소리는 0에서 약 0.3초에 걸쳐 커지고, 멈출 때 0.2초에 걸쳐 작아집니다.
- 플레이바를 끌어서 위치를 옮기는 기능은 [미정]입니다.
