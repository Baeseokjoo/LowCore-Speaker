# DetailPanel

S04에서 카드를 눌렀을 때 펼쳐지는 프레임입니다. `surface-2` 바깥 프레임 하나 안에 이미지 프레임과 상세 정보가 들어갑니다.

- 넣을 것: `kind`, `name`, `imageSide`(5인치는 `left`, 8인치는 `right` — 서로 좌우를 뒤집은 배치), `children`(상세 정보), `onBuy`(B05), `onTry`(B06, S02로 스크롤), `onClose`.
- 상세 정보는 사양 12항목을 6개씩 두 열로 놓습니다(왼쪽 열 1~6, 오른쪽 열 7~12). 각 항목은 위에 항목명(12px, `fg-muted`), 아래에 값(15px, 500, `fg`)이고 항목 사이에 `line` 구분선을 둡니다. 펼친 칸 높이 600px 안에 들어가야 합니다(2026-11-13). 데스크톱 한 화면 맞춤에서는 칸 높이가 화면 높이에 따라 456~600px이고, 세로 900px 미만에서는 상세 칸 위아래 여백 28px·항목 위아래 4px로 좁혀 456px 안에 들어가게 합니다(2026-11-16).
- 이미지 프레임은 2px `orchid` 테두리(S02 선택 테두리와 같음, 2026-11-13)와 `shadow-layer`로 상세 칸 위로 24px 겹쳐 얹힙니다. 이미지 프레임을 다시 누르면 접혀서 두 카드가 나란히 돌아옵니다.
- 버튼 순서는 구매(`primary`) → 체험하기(`ghost`)이고, 두 배치에서 같습니다. 좌우 순서 확정은 [미정]입니다.
- 펼칠 때는 상세 칸이 다른 카드가 밀려나는 방향으로 열리고, 다른 카드는 화면 끝으로 밀려나 `blur-pushed`가 되며, 약 300px만 보입니다. 이 배치는 소비하는 쪽 레이아웃이 맡습니다.
- 펼침·전환 움직임은 누르기 직전 카드(기본 카드 또는 블러 카드)에서 이미지 프레임으로, 기존 이미지 프레임에서 블러 카드로 자리·크기·테두리·블러가 이어서 바뀌는 방식입니다. 900ms, `cubic-bezier(0.4, 0, 0.2, 1)`(2026-11-13, 구현 `src/sections/modelMorph.js`).
