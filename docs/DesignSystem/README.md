LOWCORE는 음악·영상 작업용 모니터 스피커(5인치 / 8인치) 단일 상품 사이트입니다. 방문자가 같은 트랙을 PC 스피커와 LOWCORE로 번갈아 들으며 저음 차이를 직접 확인하게 하는 것이 사이트의 단 하나의 핵심 행동입니다. 이 시스템의 모든 규칙은 그 행동을 돕기 위해 있습니다. 전달할 인상은 **묵직하고 단단함, 감각적이고 세련됨**이고, 피할 방향은 **저음 과장·소비자용 느낌, 자동 재생·갑작스러운 큰 소리, 구매 강요·과한 할인 강조**입니다.

기준 화면은 데스크톱 1440px, 어두운 테마 하나입니다. 반응형 기준은 태블릿 1023px 이하, 휴대폰 767px 이하입니다(2026-11-16). 작은 화면에서는 같은 원칙을 지키면서 글자 크기·여백만 줄이고(메인카피 60 → 46 → 32px, 섹션 제목 44 → 36 → 28px, 섹션 위아래 여백 160 → 120 → 88px), 펼침이 큰 S04는 아코디언으로 바꿉니다. 세부는 PROJECT_CONTEXT 7번을 따릅니다.

## 원칙

1. **선택 = 초점, 비선택 = 블러.** S02 비교 체험과 S04 모델 선택은 같은 원리를 씁니다. 고른 것만 선명하고 나머지는 `blur-dimmed` / `blur-pushed`로 가라앉힙니다. 블러된 것도 무엇인지 알아볼 수 있어야 하고, 누르면 선택이 바뀝니다.
2. **단계적 공개.** 처음에는 이미지와 이름만 보여 주고, 고른 카드에서만 상세 정보와 버튼을 엽니다.
3. **강한 색은 지금 눌러야 할 것에만.** `orchid`는 한 화면 높이 안에 '행동' 하나만 보이게 씁니다.
4. **자동으로 소리 내지 않기.** 재생은 항상 방문자가 재생 버튼을 눌러야 시작되고, 0에서 서서히 커집니다.

## 색

- 바탕은 언제나 `bg`입니다. 그 위에 면을 `surface-1`(카드·안내 상자·안내창) → `surface-2`(S04 펼침 프레임) 순서로 한 단계씩 쌓고, 단계를 더 만들지 않습니다.
- 글자는 `fg`(제목·본문)와 `fg-muted`(서브카피·안내·라벨·메뉴)가 기본입니다. 예외로 S04 카드 제품 요약은 `orchid` 글자입니다(2026-11-13 사용자 요청, `bg`·`surface-1` 대비 7.8:1 이상). 둘 다 `bg`, `surface-1`, `surface-2` 어디에 놓여도 4.5:1 이상입니다.
- `orchid`를 쓰는 곳은 아래가 전부입니다. 채움 위의 글자는 항상 `on-orchid`입니다.
  - S01 B01 체험 시작(채움)
  - S02 선택한 이미지의 2px 테두리, 재생 버튼(채움), 플레이바 진행선 — 셋이 한 덩어리로 같은 대상을 가리킵니다
  - S04 펼친 상세 칸의 B05 구매(채움)
  - S04 카드 제품 요약 글자 (2026-11-13 사용자 요청)
  - S04 펼친 이미지 프레임의 2px 테두리 — S02 선택 테두리와 같음 (2026-11-13 사용자 요청)
  - 상단 메뉴 현재 위치: `orchid-tint` 바탕 + `orchid` 글자
  - 키보드 포커스 링(2px, 4px 띄움)
- `orchid`를 쓰지 않는 곳: 제목과 본문, 메뉴 호버, 블러 카드, B06 체험하기, 연기 배경.
- `line`은 장식선입니다. 정보를 전달하는 경계(보조 버튼)에는 3:1을 넘는 `outline`을 씁니다.
- 연기 4색(`smoke-indigo`, `smoke-plum`, `smoke-magenta`, `smoke-blue`)은 배경 전용입니다. S01 히어로에는 강하게, S02에는 약 1/3 강도로 깔고, 글자 뒤 가운데 영역은 `bg`로 어둡게 남깁니다. 틸트할 때 뒤로 비치는 빛도 `smoke-magenta`와 `smoke-plum`으로 만듭니다.
- `art-*`와 `placeholder`는 실제 제품 이미지와 문구가 들어오기 전까지 쓰는 임시 색입니다.

## 타이포그래피

- 한글은 모두 `sans`(IBM Plex Sans KR)로 씁니다. 반듯하고 기계적인 균형이 '작업의 기준'이라는 인상과 맞습니다. 섹션 라벨과 © 같은 작은 기술적 표기에만 `mono`(IBM Plex Mono)를 씁니다. 두 글꼴 모두 Google Fonts에서 불러옵니다. 워드마크는 로고 이미지로 바뀌어 `display`(Space Grotesk)는 쓰지 않습니다(2026-11-13).
- 위계는 `display` 60 → `h2` 44 → `h3` 32 → `h4` 24 → `body-lg` 18 → `body` 16 → `body-sm` 14 → `label` 13입니다. 메인카피는 서브카피보다 약 3.3배 크게 두어 대비를 분명히 합니다.
- 섹션 머리는 항상 `label`(`fg-muted`) → `h2` 순서이고, 둘 사이는 `space-2`입니다. 라벨은 메뉴와 같은 이름만 씁니다: "Experience", "Why", "Model"(2026-11-13, 번호 없음).
- 굵기는 400 · 500 · 600 · 700만 쓰고, 한글 줄바꿈은 단어 단위(`word-break: keep-all`)로 합니다.

## 간격과 레이아웃

- 여백을 넓게 쓰고, 한 묶음 안은 촘촘하게 붙입니다. 한 묶음 안의 간격은 `space-3` 이하, 묶음과 묶음 사이는 `space-8` 이상입니다.
- 12단 격자, `content-width` 1200px, 좌우 여백 `space-page`, 단 간격 `space-3`을 씁니다. 섹션 위아래 여백은 `space-section`입니다.
- S01·S02는 가운데 정렬(행동 하나에 집중), S03·S04는 왼쪽 정렬(읽고 비교)입니다.
- 같은 종류는 같은 크기로 둡니다. S02 이미지 3개는 `tile-ratio` 4:5로 같은 폭이고, S04 카드 2장도 같은 폭입니다. 이미지 안의 제품은 각 칸의 가운데에 둡니다.
- 헤더는 `header-height` 높이로 화면 위에 고정합니다. 히어로에서는 투명하고, 스크롤하면 `scrim` 바탕 + `blur-header` + 아래 `line`이 생깁니다.
- 푸터는 위에 `line` 구분선을 두고 한 줄로 놓습니다: 워드마크(맨 위로) · 섹션 바로가기 · © 2026 LOWCORE.

## 모서리와 그림자

- 손으로 누르는 컨트롤은 둥글게, 놓여 있는 물체는 각이 살아 있게 합니다(하드웨어 노브와 몸체의 관계).

## 접근성

- 모든 글자는 놓이는 바탕에서 4.5:1 이상, 테두리·아이콘·포커스 링은 3:1 이상입니다.
