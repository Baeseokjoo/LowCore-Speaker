## 1. 테스트 케이스 표

### 읽는 법

- 환경: `공통` = 모든 화면 폭 / `모바일·태블릿` = 화면 폭 1023px 이하 (1024px 이상은 데스크톱). prd.md 표기를 그대로 따른다.
- '공통' 케이스는 따로 적지 않으면 데스크톱 화면 폭 1440px에서 확인한다.
- 결과 칸에는 `통과` / `실패`를 적는다. 2번 '제외 항목'의 케이스는 실행하지 않는다. 기대 결과에 적힌 내용이 하나라도 다르면 `실패`다.
- TC-28, TC-29는 핵심 행동(비교 체험 재생)을 처음부터 끝까지 해내는 사용 흐름 케이스다.

### 준비: Chrome 개발자 도구 사용법

- 개발자 도구 열기: `F12` (Mac은 `Cmd+Option+I`)
- 화면 폭 바꾸기: 개발자 도구를 연 상태에서 `Ctrl+Shift+M`(Mac `Cmd+Shift+M`)을 누르면 화면 위에 폭 입력칸이 생긴다. 맨 왼쪽 목록에서 'Responsive'를 고르고 폭 칸에 숫자(예: 375)를 입력한다. 끝나면 같은 단축키로 다시 끈다.
- 크기·색 재기: `Ctrl+Shift+C`(Mac `Cmd+Shift+C`)를 누른 뒤 화면의 요소를 클릭한다. 오른쪽 'Computed' 탭에서 `font-size`(글자 크기), `font-weight`(굵기), `height`(높이), `color`(글자색), `background-color`(바탕색), `border`(테두리), `filter`(흐림 `blur`·밝기 `brightness`) 값을 읽는다. 마우스만 올려도 나오는 작은 상자에 크기와 'Contrast'(명도 대비) 값이 보인다.
- 동작 줄이기 켜기: 개발자 도구를 연 상태에서 `Ctrl+Shift+P`(Mac `Cmd+Shift+P`) → 입력칸에 `reduced motion` 입력 → 'Emulate CSS prefers-reduced-motion: reduce'를 고른다. 끄려면 같은 방법으로 'Do not emulate'를 고른다.
- 가로 스크롤 확인: 페이지 맨 위부터 맨 아래까지 내리면서 화면을 좌우로 밀어 보거나(터치), `Shift`+마우스 휠을 굴려 본다. 화면이 좌우로 움직이거나 아래쪽에 가로 스크롤 막대가 보이면 가로 스크롤이 있는 것이다.
- 소리는 이어폰이나 헤드폰을 끼고, 기기 음량을 낮게 맞춘 뒤 듣는다. (이어폰이나 헤드폰이 없을 시 스피커로 대체)
