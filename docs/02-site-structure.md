# LOWCORE 사이트 페이지 구성

- 기준 문서: 01-site-purpose.md
- 이 문서는 01 문서와 페이지 구성 단계에서 확정한 내용만 담습니다.

---

## 1. 확정한 내용

### 1-1. 페이지 구분
| 페이지 | 섹션 순서 |
|---|---|
| 메인 | 히어로 → 비교 체험 → 이유 설명 → 모델 선택 |

- 단일 페이지(원페이지) 사이트입니다. 모든 이동은 메인 안에서 스크롤이나 펼침으로 일어납니다.
- 별도 제품 상세 페이지는 두지 않습니다. 제품 요약, 상세 정보, 구매 버튼은 메인의 모델 선택 섹션에서 보여 줍니다.

### 1-2. 선택 사항 결정
| 항목 | 결정 |
|---|---|
| 비교 체험 위치 | 메인 안의 섹션 |
| 이유 설명 위치 | 비교 체험 바로 아래 섹션 |
| 제품 요약과 모델 선택 | 하나의 섹션(모델 선택)으로 합쳐 메인에 둠 |
| 모델 표시 방식 | 두 모델(5인치 / 8인치)을 카드 형태로 나란히 배치하고, 카드에 모델 이미지와 제품 요약을 넣음 |
| 상세 정보 표시 방식 | 카드를 누르면 같은 화면에서 상세 정보가 펼쳐짐. 상세 정보는 카드 아래가 아니라, 다른 카드가 밀려나는 방향으로 카드 옆에 가로로 펼쳐짐 |
| 하단 버튼 영역 | 펼쳐진 상세 정보의 가장 하단에 구매 버튼과 체험하기 버튼을 같은 위치에 나란히 배치 |
| 구매 버튼 | 상세 정보를 본 뒤 바로 구매할 수 있도록 하는 버튼 |
| 체험하기 버튼 | 상세 정보를 본 뒤 다시 체험해 보고 싶은 방문자를 위해 비교 체험 섹션으로 이동하는 버튼 |

### 1-3. 방문자 흐름
| # | 방문자 행동 | 필요한 정보·기능 | 배치할 페이지·섹션 | 다음 행동 |
|---|---|---|---|---|
| 1 | 사이트에 처음 들어와 무엇인지 파악 | 브랜드명, 메인카피, 서브카피, 체험 시작 버튼 | 메인 › 히어로 | 비교 체험 섹션으로 이동 |
| 2 | 체험 준비 | 헤드폰 착용 권장 안내. 자동 재생 없이 방문자가 직접 누를 때만 재생 | 메인 › 비교 체험 섹션 맨 위 | 이미지 선택 |
| 3 | 들어볼 소리 고르기 | PC 스피커 / 5인치 모델 / 8인치 모델 이미지와 '모델을 선택한 뒤 재생 버튼을 누르면 음원이 재생됩니다' 안내 문구 | 메인 › 비교 체험 섹션 | 이미지 누르기 |
| 4 | 모델을 선택한 뒤 재생 버튼으로 각 소리 듣기 (가장 중요한 행동) | 이미지를 누르면 선택되고 이미지 안 하단에 재생 버튼과 플레이바가 나타남. 재생 버튼을 눌러야 선택한 이미지(PC 스피커 / 5인치 / 8인치)에서 출력되는 소리 재생 (선택만으로는 재생되지 않음). 재생 중 다른 모델을 선택하면 소리 멈춤. 한 음원에 필터 처리로 차이 구현 | 메인 › 비교 체험 섹션 | 이유 알아보기 또는 제품 보기 |
| 5 | 소리가 왜 다른지 이해 | 기기마다 소리가 달라지는 이유 설명 | 메인 › 이유 설명 섹션 | 모델 선택 섹션으로 이동 |
| 6 | 제품 살펴보기 | 두 모델 카드가 나란히 보임. 카드에 모델 이미지와 제품 요약 | 메인 › 모델 선택 섹션 | 카드 누르기 |
| 7 | 제품 자세히 보기 | 누른 카드의 상세 정보가 같은 화면에서 펼쳐짐. 가장 하단에 구매 버튼과 체험하기 버튼이 나란히 있음 | 메인 › 모델 선택 섹션 › 펼쳐진 상세 정보 | 구매 버튼, 체험하기 버튼, 또는 다른 카드 선택 |
| 8 | 바로 구매 | 구매 버튼 (결제 화면은 만들지 않음) | 메인 › 모델 선택 섹션 › 펼쳐진 상세 정보 › 하단 버튼 영역 | 추후 결정 |
| 9 | 다시 체험 | 체험하기 버튼 | 메인 › 모델 선택 섹션 › 펼쳐진 상세 정보 › 하단 버튼 영역 | 메인 › 비교 체험 섹션으로 이동 |

### 1-4. 모델 선택 섹션의 동작
- 처음 들어왔을 때: 두 모델 카드가 나란히 보이고, 각 카드에 모델 이미지와 제품 요약이 들어감
- 카드를 누르면: 누른 카드가 선택되고 자연스럽게 확대되며 이미지 아래 텍스트(모델명, 제품 요약)가 사라짐. 다른 카드는 옆으로 밀려나며 블러 처리됨. 상세 정보는 다른 카드가 밀려나는 방향으로 선택된 카드 옆에 가로로 펼쳐짐 (예: 5인치 선택 시 8인치가 오른쪽으로 밀려나고 상세 정보도 오른쪽에 펼쳐짐)
- 블러 처리된 카드를 누르면: 선택이 그 모델로 바뀜
- 펼쳐진 상세 정보 구성 (카드 옆 영역 안): 위에 상세 정보 내용, 가장 하단에 구매 버튼과 체험하기 버튼이 같은 위치에 나란히 배치됨
