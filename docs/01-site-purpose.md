# LOWCORE 사이트 목적 정의

- 브랜드: LOWCORE (로우코어)
- 상품: 음악·영상 작업용 모니터 스피커
- 메인카피: 들리지 않던 저음까지, 작업의 기준이 되는 스피커 LOWCORE.
- 서브카피: 같은 트랙을 PC 스피커와 LOWCORE로 번갈아 들으며, 저음의 차이를 직접 확인해 보세요.

---

## 1. 사이트 목적 한 문장

유튜버·영상 편집자와 홈레코딩 입문 작곡가가 PC 스피커와의 저음 차이를 직접 들어보고, 소리가 달라지는 이유를 이해하도록 돕는다.

## 2. 주요 방문자와 방문자의 필요

### 주요 방문자
- 유튜버·영상 편집자
- 홈레코딩 입문 작곡가

### 방문자의 필요
- 소리가 기기마다 달라지는 이유를 이해하는 것
- 사기 전에 PC 스피커와의 차이를 직접 확인하는 것

## 3. 가장 중요한 행동과 보조적인 행동

### 가장 중요한 행동
- 비교 체험 재생: 같은 트랙을 PC 스피커와 LOWCORE로 번갈아 듣기

### 보조적인 행동
- 제품 상세 보기 → 구매
- 구매는 구매 버튼까지만 다루고, 결제 화면은 만들지 않는다.

### 체험 구성
| 항목 | 확정 내용 |
|---|---|
| 제품 구성 | 크기별 2종(5인치 / 8인치), 모델마다 체험 가능 |
| 비교 방식 | PC 스피커 vs 방문자가 선택한 모델 |
| 체험 트랙 | 저음이 뚜렷한 1곡. 곡은 직접 선정하며, 베이스 차이를 선명하게 들을 수 있는 붐뱁 비트로 고를 예정 |
| 소리 차이 구현 | 한 음원에 필터 처리 |
| 청취 환경 안내 | 체험 전 헤드폰 착용 권장 안내 |
| 주 접속 기기 | 데스크톱 기준으로 진행, 모바일은 반응형으로 처리 |

## 4. 전달하고 싶은 인상과 피하고 싶은 방향

### 전달하고 싶은 인상
- 묵직하고 단단함
- 감각적이고 세련됨

### 피하고 싶은 방향
- 저음 과장·소비자용 느낌
- 자동 재생·갑작스러운 큰 소리
- 구매 강요·과한 할인 강조

## 5. 기획을 위한 가정

없음. 모든 항목을 직접 확정함 ('추측해서 정해줘'로 답한 항목 없음).

## 6. 다음 단계에서 결정할 내용

- 체험 트랙 곡 선정: 직접 고를 예정 (붐뱁 비트 중에서 베이스 차이가 선명한 곡)
- 사이트 페이지 구성
