# [프로젝트 이름]

> 음악 및 영상 편집 작업자 대상으로 데스크탑 중심의 스피커 비교 체험 및 소개 웹페이지 제작

## 1. 링크

- **Live Demo**: https://baeseokjoo.github.io/LowCore-Speaker/
- **GitHub**: https://github.com/Baeseokjoo/LowCore-Speaker
- **Figma 디자인**: https://www.figma.com/design/PCKvGX1rVF93q6g0Yz2cdP/LowCore?node-id=0-1&t=BpYgclROmPNskwFK-1

## 2. 프로젝트 정보

- **제작 기간**: 2026.11.12 ~ 2026.11.16 (05일)
- **담당 역할**: 개인 프로젝트 (기여도 100%)
- **담당 범위**: Figma 개선 디자인 → 바이브코딩 구현 → GitHub Pages 배포

## 3. 사용 기술

- **React, Vite**: Figma에서 디자인을 구성하고 그에 맞게 화면을 컴포넌트로 구성하며 수정하기 쉽게 설정하기 위해 사용
- **GitHub Pages**: 무료 배포
- **Figma**: 개선 디자인
- **Claude**: 바이브코딩 (화면 구현)

## 4. 주요 기능

- 기능 1 : 히어로 섹션 내에 체험하기 버튼 배치
- 기능 2 : 사용자들이 제품을 실시간으로 비교해볼 수 있는 비교 체험 섹션 구성

## 5. 트러블슈팅

### 이슈 1: GitHub에 첫 커밋 및 푸쉬 이후 배포가 되지 않음

- **문제**: GitHub에서 푸쉬 이후 배포할 수 없는 상태의 오류가 발생함.
- **원인**: Pages에서 Source를 GitHub Actions로 변경하지 않았음.
- **해결**: Source를 'Deploy from a branch -> GitHub Actions'로 변경 후 빈 커밋으로 workflow를 다시 실행시켜 배포함.

## 6. AI 활용 방식

- **맡긴 일**: 스피커 별로의 소리의 차이를 느낄 수 있도록 설정.
- **핵심 프롬프트**: "[음원 첨부] 해당 음원을 재생버튼을 클릭 시 실행이 되도록 설정해줘. 또한 플레이바는 음원재생의 진행 상태를 나타나도록 설정해줘. 각 스피커의 종류별로 저음필터를 사용해서 구현하도록 할거야."

## 7. 회고

- **배운 점**: 데스크탑에서 구현하려는 이펙트들이 모바일에서 보여질 경우 구현하기 어려운 부분들이 있음. 예를 들어 데스크탑에서 마우스가 호버 시 틸트효과가 나타나도록 구현을 하지만 모바일과 같은 터치로 사용되는 디바이스에서는 보여지기 어려움. 그래서 데스크탑과 모바일에서 보여지는 형태를 각각 생각하면서 구성할 수 있어야 함.
- **아쉬운 점**: 실제 존재하는 상품이 아니라 내가 생각한 제품으로 웹페이지를 제작한 것이기 때문에 이미지들을 AI를 이용하여 구성함. 어떠한 이미지가 필요하고 내가 원하는 이미지가 분명히 있었지만 원하는 결과물을 얻기 위해 프롬프트를 작성할 때에 원하는 방향대로 자세히 설명하는 부분에서 어려움을 겪었다. 이후에 이미지 생성을 위해서는 전체적인 이미지의 구체적인 방향, 구성 등을 명확하게 작성할 필요가 있음.
